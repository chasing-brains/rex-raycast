# Rex Sessions

Search [Rex](https://www.superlogical.com/rex) sessions, tabs, and panes from Raycast. Preview terminals and jump with Enter.

Install Rex and enable **Rex → Settings → Rex Server → Remote Control**.

```sh
npm ci
npm run dev
```
